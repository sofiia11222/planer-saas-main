1. Подключение Firebase (один раз)
  1. Откройте console.firebase.google.com (нужен Google-аккаунт)
  2. Создайте проект → добавьте приложение Web (</>)
  3. Скопируйте конфиг вида apiKey, projectId…
  4. В Firebase: Build → Firestore Database → Create (режим test на 30 дней или правила ниже)
  5. Вставьте конфиг в поля ниже и нажмите «Сохранить конфиг»

Правила Firestore (для личного использования, Rules → Publish):

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /spaces/{spaceId} {
      allow read, write: if true;
    }
  }
}

⚠ Эти правила открыты: знайте свой «код пространства» и не публикуйте его. Для личного Mac + iPhone этого достаточно.

2. Код пространства

Один и тот же код на телефоне и ноутбуке = общие данные. Придумайте длинный секретный код (как пароль).

Как пользоваться
  1. На MacBook: сохраните конфиг → введите код → «Подключить»
  2. На iPhone: откройте тот же HTML-файл → тот же конфиг и тот же код → «Подключить»
  3. После этого сохранения сами уходят в облако; при открытии подтягиваются с сервера
